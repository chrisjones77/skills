# WordStar 3.3

Set a 12-pitch document with a centred, emphasized heading and consistent paragraph indents. WordStar’s margin and print controls allow a whole document to be reflowed. The repeating hyphen-width rules stand in for a typed separator. Dot commands belong in the authoring file. Use the page to show their result.

Select `wordstar` for flyer, notice, memo, letter. Place the copy in the main slot.
