# PageMaker / LaserWriter PostScript

Build the page as a pasteboard composition. Use a generous roman headline, an italic secondary line and an independently placed vector ornament. The PDF uses modern TeX Gyre Termes OpenType/CFF faces with cubic outlines. The renderer also writes a monochrome Level 1 document.ps using Poppler pdftops. Chromium encodes the CFF-derived shapes as Type 3 glyphs in the PDF.

Select `pagemaker` for flyer, notice, letterhead. Place the copy in the main slot.
