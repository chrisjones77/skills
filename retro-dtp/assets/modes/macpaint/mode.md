# MacPaint 1-bit

Work in black and white. Build tonal areas from repeated black pixels and use a silhouette for the foreground. The landscape starter is a 248 × 88 one-bit PNG. Preserve its hard pixel edges when enlarging it. Use stepped text as an editable stand-in for lettering committed to the original paint canvas.

Select `macpaint` for flyer, notice. Place the copy in the main slot.
