# Windows 3.1 TrueType

Use the early Windows office combination of a scalable sans heading, serif body and fixed-pitch identifier. Place emphasis through size, weight and paragraph alignment. Liberation supplies modern TrueType substitutes. Windows 3.1 is the chosen reference. System 7 had shipped TrueType in 1991. The PDF uses current font rasterization.

Select `windows-truetype` for flyer, notice, memo, letterhead. Place the copy in the main slot.
