# Field evidence and measurement

Record date, plot and source for each claim. Tag it as observed, measured, reported, estimated, inferred or unknown. State which parts of a plot a photo shows. Use a scale reference before estimating size. Record alternate explanations and the next observation that would distinguish them. Keep cultivar and yield unknown where evidence is insufficient.

Record measured net weight separately from estimates. Record tare and scale method, units and destination. Add confirmed measurements once after normalizing units. Link transfers, corrections and later weigh-ins to the original row so they do not inflate harvest totals.

For a photographic overlay, keep the source separately and draw on a copy. When exact pixel preservation is requested, use lossless output. Decode source and output into the same pixel format and compare against the corresponding source crop outside the annotation mask, including any antialiasing. Report the comparison only if it ran.
