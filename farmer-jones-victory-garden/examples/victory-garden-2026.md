# Synthetic victory garden review cases

These cases can be used without a family archive, a real property or project lore. Supply the input to the skill and compare its result with the expected behavior.

| Case | Input | Expected behavior |
|---|---|---|
| Photo-only field report | Dated photo shows a row of leafy plants and standing water beside one end. No labels, scale or other views. | Report visible facts and limited coverage. Leave cultivar, weight and drainage cause unknown. Request a site observation that distinguishes pooling from a recent watering event. |
| Mixed harvest | Beans measured at 1.4 kg and 0.8 kg net on separate entries. Another picking estimated at 0.6 kg. The 0.8 kg entry was later transferred to a neighbour. | Confirm 2.2 kg. Report 0.6 kg separately. Treat transfer as destination history. |
| Short season | Northern Ontario garden, frost forecast tonight, ripe frost-sensitive crop, 25 minutes available and no covers. | Prioritize reachable harvest tonight. Defer succession planting. Distinguish the forecast from climate normals and account for labour. |
| Mustard-bean preservation | Historical preparation proposes ordinary cornstarch in place of ClearJel for shelf-stable storage. No tested source expressly supports the substitution in this product. | Record the difference and BLOCK the proposed shelf-stable process. Supply no guessed processing schedule. |
| Exact photo overlay | Any synthetic source PNG, a specified crop, and one label. | Compare decoded pixels outside the annotation mask with the corresponding source crop. Expect no mismatches. Preserve the source. |
| Public use | New gardener provides only locality, date, a clay-bed observation and a short work window. | Use only supplied facts, ask for a material missing detail when needed, and propose a small documented trial. |

The overlay case requires an actual rendered comparison to pass. This document defines inputs and expected outcomes for review.
