# QVCH

QVCH stands for Quantum Vibe Coding Harness. It uses the [Engineering Work and Safety mode table](https://github.com/chrisjones77/skills/blob/6986c69ae9ad2f5990b0fedc40cd3261c8d87543/engineering-work-safety/references/framework.md#orientation-task-classes-and-command-words) as the source for task classes and command words.

1. **Orient (0x0).** Identify the desired outcome, the people and systems affected, and the constraints that matter.
2. **Select one primary mode (0x1–0xF)** and its command word. Add up to two companion lenses when they help answer a distinct question.
3. **Choose the relevant guidance.** If the project declares a routing overlay, use it to find applicable skills and their approved sources. Resolve each skill by source and revision. Surface unavailable guidance when it affects the task.
4. **Check authority.** Derive permissions from governing instructions and the user's authorization. The mode and routing overlay describe the work and its guidance.

For routine work, a brief orientation and primary mode are enough. Proceed with the relevant guidance and record only what helps with the task. For a scoped assignment or formal handoff, carry the purpose into the [Unified Work Harness](https://github.com/chrisjones77/skills/tree/f8195f6d7606edce9ccebaa334a10b8a5132c3d2/unified-work-harness) contract along with the outcome, scope, workspace, permissions, evidence, and review owner.

A project overlay can name approved skill sources, map command words to local procedures, and record project-specific constraints. It can stay in the project repository and be reviewed independently. Follow the active repository and runtime instructions when selecting or applying it.
